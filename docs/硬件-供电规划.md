# 硬件供电规划与上电自查表

> 任务来源：M0-08 ｜ 风险关联：R4（舵机+喇叭+屏共用 USB 5V 会 brownout）
> 关联任务：M0-07（接线）、M2-06（舵机）、M2-08（独立供电验证）

## 1. 负载预算

| 用电设备 | 典型电流 | 峰值电流 | 供电来源 |
| --- | --- | --- | --- |
| ESP32-S3 N16R8 主板（WiFi 发射） | 100~250mA | 500mA | USB 口 5V |
| GC9A01 圆屏 | 40~80mA | — | 3.3V（主板 LDO） |
| INMP441 麦克风 | ~2mA | — | 3.3V |
| MAX98357A 功放（最大音量） | 50~150mA | **300mA** | 5V 直供（模块 VIN） |
| SG90 舵机 ×2（静态） | 20mA | — | **独立 5V** |
| SG90 舵机 ×2（动作/堵转） | 300~700mA | **>1A** | **独立 5V** |

**结论**：USB 2.0 口保证 500mA，喇叭峰值 + WiFi 峰值叠加已逼近上限；舵机峰值 >1A 绝不能挂 USB——**舵机必须独立供电**。

## 2. 舵机独立供电接法

```
独立 5V 电源(≥2A) ──┬── 舵机1 红线(VCC)
                    ├── 舵机2 红线(VCC)
                    └── ⚠ 与主板 GND 共地（关键！）
独立 5V GND ────────┴── 主板 GND ── 舵机 棕色线(GND)
ESP32 GPIO ──────────── 舵机 橙色线(信号 PWM)
```

三条铁律：
1. **共地不共电**：独立电源的 GND 必须与主板 GND 连通，否则 PWM 信号无参考电平，舵机会乱抖。
2. **信号线直连**：GPIO → 舵机信号线中间不加电阻分压（5V 舵机信号高电平 3.3V 一般可识别；若某舵机不响应，换 1kΩ 上拉到 5V 试验）。
3. **大电容缓冲**：独立 5V 入口并联 470µF~1000µF 电解电容，吸收舵机启停浪涌。

## 3. USB 口分配（风险 R3 决议）

| 口 | 用途 |
| --- | --- |
| `USB` 口（原生 USB-Serial-JTAG） | **只跑协议通信**（protocol.md 的 CDC 链路） |
| `COM` 口（CH343） | 只做烧录 + `idf.py monitor` 日志 |

## 4. 上电前自查清单

- [ ] 万用表蜂鸣档：5V↔GND、3.3V↔GND 无短路
- [ ] 独立 5V 与主板 GND 已连通（电阻 <1Ω）
- [ ] 舵机电源线极性正确（红+棕-，接反必烧）
- [ ] 喇叭线接 MAX98357A 输出端（不是接反到输入）
- [ ] 所有模块 3.3V/5V 供电等级核对（INMP441 只能 3.3V！MAX98357A VIN 可 5V）
- [ ] 杜邦线插紧（面包板孔氧化是头号玄学故障源）
- [ ] 首次上电只接主板单板 → 空载烧录成功 → 再逐个外设接入

## 5. 故障对照速查

| 现象 | 最可能原因 |
| --- | --- |
| 上电瞬间重启循环（log 刷 boot） | brownout：供电不足，查舵机/喇叭是否挂 USB |
| 舵机乱抖不听指令 | 未共地 |
| 舵机完全不动 | 信号线接错 GPIO / LEDC 未配置 |
| 麦克风全是无声噪声 | INMP441 接了 5V（烧毁风险，立即断电） |
| 屏幕白屏/花屏 | SPI 线序错 / 3.3V 供电不足 |
